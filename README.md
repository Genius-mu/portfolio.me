## 🚀 Overview

This portfolio was built to highlight my work and technical growth as a full stack developer.  
It features a clean, modern design powered by **React** and **Tailwind CSS**, with smooth animations, responsive layouts, and an interactive contact form — all backed by scalable backend infrastructure.

You'll find details about my **full-stack projects**, **technical expertise**, **API design**, and **ways to connect** — all crafted to reflect my passion for building complete, production-ready web solutions from database to UI.

## 🛠️ Tech Stack

### Frontend
- ⚛️ **React** — Component-based UI development
- 🎨 **Tailwind CSS** — Utility-first responsive styling
- 📧 **Formspree + Formik** — Form validation and submission
- 🧠 **JavaScript (ES6+) / TypeScript** — Logic and interactivity
- 🧩 **Next.js** — Full-stack React framework
- 🌍 **Framer Motion** — Smooth animations

### Backend & Database
- 🟢 **Node.js** — JavaScript runtime for scalable APIs
- 🚀 **Express.js** — Backend framework
- 📦 **MongoDB / PostgreSQL** — Database design and optimization
- 🔐 **Authentication** — JWT, OAuth implementations
- ⚙️ **RESTful APIs** — API design and development

### DevOps & Tools
- 🧩 **Vite** — Lightning-fast development environment
- 🌍 **Netlify / Vercel** — For deployment
- 🐙 **Git & GitHub** — Version control
